## Inventory decisions made in this loop

- Removed the intake contact-hours toggle because it did not actually remove the generated workload model; a visible control cannot be a placebo. Contact-hour planning remains a standard, editable course capability.
- Reworded unverified Canvas claims to “Canvas-oriented” and “locally validated.”
- Added an actionable, undoable “Fix all safe issues” path directly in readiness.
- Added reusable modal focus containment and focus return for editor review, welcome, and readiness dialogs.
